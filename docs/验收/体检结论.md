## 重要修复根因

- **窗口内存增长（HUD）**：切窗 HUD 前 120 ms 的 scale 连续经过 0.92–1.0，原代码用 `SWITCH_HUD_TEXT * scale` 排版；GPUI `RenderGlyphParams` 以 `font_size.0.to_bits()` 为键，App 级 `TextSystem`／共享 Atlas 不随关窗淘汰，于是每个新时刻都插入新字形。修复只在 `text_size(scale)` 中 `.round()`，动画区间只有 92–100 px 共 9 个字号。
- **CPU 单位**：`sample_resources.py` 把 `proc_pid_rusage` 的 Mach ticks 当纳秒，本机 timebase 125/3，低估约 41.67 倍。统一读取 `mach_timebase_info`，按每进程读取时刻算间隔。旧 5 分钟 p95 由 `0.000552%×41.6667` 修正为 0.0230%。
- **按键计时终点**：旧 `key_latency` 止于绘制前回调。新口径从 macOS 去重后 keyDown、IME／GPUI 分发前起，到同窗口下一次成功 Metal `commit()` 返回，字段 `key_cpu_submit_p99_ms`。不含 GPU 完成、合成器呈现和 scanout，不能替代「按键到画面」预算；Diff 的 `frame_upper` 不用于按键统计。
- **Diff 刷新**：见第 15 项；同时确认 M→M 时版本与补丁实测均变化，外部暂存与提交后的 Diff 变化符合语义。
- **自动保存**：默认 `afterDelay`（编辑停顿 1 秒），显式 `off` 保留；延时回调复核当前模式；接入源码编辑器与 Markdown 块的 `InputEvent::Blur`；菜单勾选随全局设置有界同步。未命名文件不自动弹面板，已删除文件不自动重建。
- **审阅写入**：逐处决策持串行锁，用同一份内容校验显示补丁与块序号；该锁不覆盖 Agent 自有工具或外部程序写入。
- **部分补丁**：除 mode 外，回归发现不等长替换的选中行错位，改用 Diff 显示层的单调行映射，不再维护第二套配对算法。

## 资源口径与历史测量

口径：footprint 用 physical footprint（含 Git 子进程）；预算窗口为加载完成后约 10 秒起连续采样 30 秒，原样本不裁剪、不因高值重跑；诊断窗口独立写入 JSON 并拒绝重叠参数。空闲 CPU 100% = 一个逻辑核心，用户于 2026-10-22 将上限从 0.1% 调为 **1%**（目标仍接近 0%），历史 0.1% 门槛下的结论不改写。门槛调整不等于性能优化。
