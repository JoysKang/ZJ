### Standards

初审发现 3 项，均已修复并复查：

1. 继承的 `GIT_DIR`、`GIT_WORK_TREE`、`GIT_INDEX_FILE` 等变量可能将夹具写入或查询导向其他仓库。服务、夹具和画像工具已清除继承的 `GIT_*`。带定位变量的夹具验证保留了哨兵仓库原状，服务身份查询也未被重定向。
2. 初版画像使用 status，Git 可能读取源文件或运行 clean filter。修订后只统计路径与文件元数据，重新生成报告；带 clean filter 的复查未触发过滤器。开发记录保留了首次运行的限制说明。
3. 仅杀死直接 Git 子进程后等待管道读取线程，可能被持有管道的后代进程拖住。已改为进程组、非阻塞有界读取和覆盖管道 EOF 的 deadline。超时、父进程提前退出、取消三种复查均约 1 秒返回，后代进程已清理。可重跑的检查保留在 `tools/check_git_deadlines.py`。

复查结果：修复范围未发现剩余可执行问题。

### Spec

初审发现 3 项，均已修复并复查：

1. 已暂存 rename 的 diff 需要同时传入原路径和新路径。已保留原始路径字节并传入两端，集成测试验证 rename from/to。
2. 刷新后旧 diff 可能被接受。刷新会使预览失效，应用结果前校验预览 generation、当前快照 generation、回复 RepoId 与 generation。
3. 仅显示仓库 basename 会使同名嵌套仓库难以区分。分组改为工作区相对路径，必要时显示完整路径，并补充辅助功能标签。

复查结果：修复范围未发现新增可执行问题。P0 / P1 未完成的实机验收仍列在开发记录中。
