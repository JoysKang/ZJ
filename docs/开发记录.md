# 开发记录

需求见[开发说明](../轻量代码编辑器开发说明.md)，模块分工与编码约定见 [CLAUDE.md](../CLAUDE.md)。本文件按里程碑压缩，只保留功能范围变化、架构决策入口和当前状态；逐批过程保留在 Git 历史，原始采样集中到 `验收/数据/`，已被取代的数值不在此复述。最终验收结论归并到 `验收/体检结论.md` 与 `验收/原生验收.md`。

## 里程碑

### 2026-09-30 首批原型

- 建立 `core`（RepoId、DocumentId、Git 标记校验）、`git_service`（porcelain v2、限流、超时、取消）和 `app`（GPUI Kit 0.7.0 真实编辑器、多工作区）三个 crate。
- 首批不含 Agent、终端、LSP 与网络 Git。G1 自此为「待验证」，至今仍未完整通过。

### 2026-10-01 工作台与自动刷新

- 改为 VS Code 式布局：活动栏、资源管理器、源码管理、搜索、文件标签和真实编辑；受限文件读取与原生打开文件夹/文件入口。
- 共用原生监听器加按窗口订阅替换轮询，刷新改为静默、不再显示扫描或陈旧标记；Diff 在查询期间也能打开。
- 单窗口启动、新建窗口（上限 5）、ZJ 命名、双栏 Diff、暂存/提交/推送与未跟踪文件比较。

### 2026-10-02 保存、搜索与渲染内存

- 仓库发现最多 4 层；紧凑快速打开索引、全文搜索、侧栏替换（行内预览、替换前 Diff、原子写入）。
- 保存全流程（`save.rs`）：临时文件 + fsync + rename、权限/换行/BOM、外部修改检测与比较、自动保存、退出询问；Agent 可读未保存缓冲区。
- `vendor/` 引入带补丁的 macOS 渲染器：双缓冲、路径纹理按需分配与空闲释放、隐藏窗口归还 drawable（决策/0005-渲染内存.md）。第 6 批体积增量单独记录（决策/0003-功能体积.md）。

### 2026-10-03 日常使用功能铺开

- 未推送提交列表、分支签出、fetch/pull/push/同步、Git 图（车道布局移植自 VS Code Git Graph）、重启恢复窗口与标签。
- 内置终端（决策/0006-内置终端.md）、Markdown 分块实时预览、缩进识别与软换行、行编辑命令、转到行、命令面板、重开已关闭标签。
- Agent 无文件夹时在默认工作区运行，新会话默认 Codex。范围已超出开发说明的「首版之外」，以本记录和决策文件为准。

### 2026-10-07 提交区与 Agent 交互

- 源码管理常驻提交区与 AI 提交信息：独立只读会话，只读暂存或工作区 diff，不暂存、不提交。
- Agent：接受修改后回到源文件并保留显示位置、运行中追加指令、额度浮层与实时查询、图片输入、按轮次折叠输出、审批卡显示原始命令与工作目录；退出时同步关闭 Agent 进程池。
- 保存与关闭按文本版本和路径核对，另存为预留规范路径；恢复快照失败经后台事件立即上报。
- GPUI Kit 升到 0.7.1 并迁移 vendor 补丁，footprint 变化的取舍见 决策/0008-GPUI升级.md。

### 2026-10-08 Agent 桥接与输入

- 去掉 Node/npm 适配器：新增 `agent_bridge`，由 ZJ 可执行文件以 `--agent-bridge` 驱动 `claude -p` 和 `codex app-server`；只用本机 CLI，缺失或过旧时给出安装命令（决策/0009-Agent桥接.md）。
- 问题卡片支持多选与自填答案，系统通知替代提示音，权限请求 id 全应用唯一，慢 hook 显示为执行步骤，输入法跟随焦点，标签栏自动换行。

### 2026-10-09 ~ 10-10 文件操作与通知

- 文件栏多选、Finder 拖入复制、排他创建与符号链接防护；SCM 仓库按名称固定排序；Agent 回复中的目录链接可在 ZJ 打开；图片附件编号、正文引用与大图预览。
- Agent 子 Agent 回收、HTTP MCP 只读验证、运行中内存现场分析；Git 写失败统一弹窗；Agent 完成改用可点击回到会话的系统通知。

### 2026-10-11 ~ 10-12 视觉与组件统一

- 统一原生组件细节（快速打开/命令面板、导航、下拉、审批卡、代码块标题栏、选区操作 ⌥⌘L），随后收紧导航与标签；按用户反馈恢复 Solarized Dark，浅色沿用 Nord Light。
- 留白与圆角成为约定：外侧 2 px、面板间距 4 px、标题栏 33 px、搜索框 28 px；常规 UI 调整不得替换主题配色。
- 评估 GPUI Kit 0.7.3 与 GPUI Fast：新后端未覆盖现有 vendor 补丁，低内存收益未建立，暂不采用（[界面与依赖调研](调研/界面与依赖.md)）。

### 2026-10-13 导航、语法与编辑细节

- import 参与跨文件跳转排序，tree-sitter locals 做局部变量同色绑定；不跑语言服务器（决策/0002-代码导航.md）。
- 语法批次 5、6（Ruby/PHP/Zig/Make、Swift/C#/CMake/Proto/Kotlin/Lua），GraphQL 与 Elixir 不入，CI 预算调整到 52 MB（决策/0001-语法支持.md）。
- 字号统一 13、Nord Light 主表对齐 VS Code；SCM 目录树与目录链合并、Diff 内 ⌘点击/⌃G、增量高亮复用；可编辑隐藏规则 `hidden_files`；按事件检查远端与「拉取 N」入口；文件树拖拽移动。

### 2026-10-14 冲突与操作反馈

- 外部合并与冲突优先刷新；冲突条提供采用当前/传入/双方与只读比较，解决后保存并暂存。
- 首次 Diff 分段计时开关（`ZJ_DIFF_TIMING_LOG`，默认关）：两秒卡顿未被复现，排查暂缓，不作为性能修复。
- 外部文件夹粘贴读取系统剪贴板、拖拽原位释放清理预览、SCM 同步箭头旋转。

### 2026-10-22 ~ 10-23 体检、原生验收与收尾

- 全面体检与后续修复：原生按键计时改到 Metal CPU 提交、HUD 动画字号取整、干净标签关闭按钮常驻、SCM/搜索常驻入口与忙碌态、提交禁用原因、查找/终端/选择浮层/大文件查看窄布局、快速打开等待与无结果反馈、取消选择面板恢复焦点。
- 新增原生保存、恢复和终端交互测试；体检与 UI 范围在 10-23 冻结。
