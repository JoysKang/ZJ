# ADR 0007：Agent 图片附件与实时额度查询

日期：2026-10-07。状态：已采纳。

## 背景

Agent 输入区需要显示图片并允许删除；只发送文件路径不能保证 Agent 收到图片内容。原有额度按钮重新读取本地会话日志，数据可能停留在上一轮请求。用户同时要求收起执行过程和修改文件列表。

## 决定

- 直接使用依赖树中已有的 `image =0.25.10` 和 `base64 =0.22.1`，不启用额外 feature。读取、解码、缩略和编码均在后台完成，界面只绘制预先生成的小图片。图片非阻塞打开后校验普通文件；压缩内容总大小上限 16 MiB，单次解码分配上限 64 MiB，最多 8 张。切换会话使未完成的附件任务失效，移除或发送后释放预览资源。
- ACP 提示新增图片内容块，保留原始图片字节和 MIME 类型。使用初始化声明的图片能力，不支持时显示错误；不把图片退化为文本路径。图片内容不写入会话数据库，历史记录只保存名称或路径。
- 悬停和点击额度按钮时，通过短时 `codex app-server` 连接调用 `account/rateLimits/read`。复用现有本机、环境配置和内置 Codex 查找规则；不运行 Agent 回合，不自动安装，不由 ZJ 读取凭据。响应行上限 64 KiB，连接有 20 秒截止时间，结束后回收进程组。采用 [OpenAI Docs 的额度接口](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)，以成功查询时间标注实时结果；查询失败保留错误和缓存的实际时间。
- 额度详情使用 Kit 的 `Popup`，锚定额度按钮并受窗口边界约束。每轮中间回复、工具调用和普通通知归入一个执行过程，运行时默认展开，可手动折叠；运行中追加指令不拆分轮次，结束后自动收起当前过程并单独显示最终回复。待审批、待登录和会话错误直接显示，展开成员仍是虚拟列表的独立行。底部跟随最新输出，向上阅读时保持位置，返回底部后恢复跟随。上下文占用圆环不再显示，额度按钮保留。修改文件列表每个新轮次默认收起，当前轮的更新和追加指令不覆盖用户手动展开的选择。

## 代价

在 M5 Pro、macOS aarch64、`--profile dist` 上测量：

| 指标 | 修改前 | 修改后 | 差值 |
| --- | --- | --- | --- |
| normal 依赖树去重行数 | 609 | 609 | 0 |
| 二进制字节数 | 28,932,720 | 29,231,056 | +298,336 |
| 单窗口空闲 physical footprint | 77.58 MB | 74.60 MB | −2.98 MB |

体积增加超过 200 KB，故记录本决策；最终体积低于 30 MB 目标及 32 MB 上限。内存比较使用相同临时工作区、单个 Rust 文档和独立配置，等待 10 秒后各采样 5 秒，结果在 `target/agent-ui-resources.json`。该短采样用于依赖准入的前后比较，不作为完整性能验收；CPU p95 分别为 1.82% 和 1.75%，均未达到项目 0.1% 目标，未观察到新增常驻定时器，修改后采样期间无出帧或 display link 唤醒。

## 验证与限制

无头 UI 测试覆盖额度悬停、再次点击、弹窗锚定，图片粘贴、普通文本粘贴、删除和仅图片发送，以及 200 项过程的展开与收起。模拟进程覆盖额度握手、错误、截止时间和本机 / 配置 / 内置 CLI 选择；临时 FIFO 验证图片读取不会阻塞。已用本机已登录 Codex 执行一次实际只读额度查询，返回可用额度窗口；未向真实模型发送测试图片。
