# ZJ 工作台视觉调整

日期：2026-10-11。问题：前一轮主要优化控件细节，整体变化仍不明显；本轮调整整个编辑器的表面层次、导航和标签，并参考现代 Agent 工具。基线：`e1472ec`。

## Git 与范围

已将 `ui/native-visual-refresh` 快进合并进本地 `main`，再创建 `ui/modern-workbench`。本轮未推送远程，未删除分支；正在运行的 ZJ 不重启。

实现仍使用 GPUI Kit 0.7.1，不增加依赖、WebView、设置或常驻动画。语法高亮和终端 ANSI 色表保留。Git 状态色保留原语义，暗色冲突文字略微提亮，以满足悬停底色上的对比度。

## 六项调整

1. **表面层次。** 恢复上一轮的中性冷色调，保留窗口框架、侧栏、编辑区、输入区与浮层的表面区分；主要操作、焦点和选中状态沿用原主题色，提交按钮配色同步恢复。
2. **边框与浮层。** 减少侧栏和 Agent 标题的重复分隔；输入区失焦时使用浅边，聚焦时加强边框。搜索、快速打开、选区操作和 Agent 浮层共用轻阴影。
3. **侧栏导航。** 文件、搜索、源码共用紧凑轨道和活动胶囊，活动项用字重辅助区分；去除重复标题。工作区标题、新建、Git 刷新和更多操作保留，源码管理标题行收紧为「仓库」。
4. **文件标签。** 活动标签增加独立底色、短顶部强调线和字重，其他标签弱化。保留 36 px 标签高度、自动换行、20 px 关闭槽、未保存圆点与关闭确认。
5. **文字与图标。** 沿用现有字号，以字重和次要文字色建立层次。文件树普通、新建、重命名目录和 Agent `@` 目录候选统一为线框文件夹图标，文件类型图标保留。
6. **Agent 控件。** 上下文标签使用轻量底色与细边；Agent、模型和模式选择器视觉减弱，保留紧凑位置和原操作。输入区轮廓更清楚。

Agent 输出结构、实际输入高度、输入和输出间距、图片、运行中追加指令、命令补全、审批与滚动规则沿用现有实现。执行过程运行中展开、结束后折叠；修改文件列表独立默认折叠。
