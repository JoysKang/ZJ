# 原生 UI 统一样式尝试

日期：2026-10-11。分支：`ui/native-visual-refresh`，基线：`88c9afc`（`main`）。

## 需求与范围

用户授权先提交本地已有工作，再切分支尝试统一 ZJ UI。沿用现有 GPUI Kit 0.7.1；参考 shadcn 与原生编辑器的视觉规则，在整个工作台使用中性冷色的明暗主题。

- 区分标题栏／标签栏、侧栏、编辑区、输入区与浮层的明暗层次。
- 统一应用控件与 Kit 默认按钮、次按钮、主按钮的正常、悬停和按下状态，以及焦点、边框和圆角。
- 命令中心显示工作区名与快捷键，长名称截断；侧栏活动按钮区分选中和悬停；非激活文件标签提供悬停反馈；快速打开与菜单使用相同的浮层表面。
- 保留正文 14 px、工作台行高、紧凑标签自动换行、点击／键盘操作，以及 Agent 消息结构、执行过程折叠、文件列表折叠、滚动和输入逻辑。
- 不增加依赖、WebView、常驻动画或新设置。所有色值与尺寸仍集中在 `theme.rs`。

旧工作已先保存为 `6c8719f`（Agent 消息滚动／模型选择器）和 `88c9afc`（调研记录）。本次视觉实验与这些修复分离，未推送远程。

## 设计取舍

暗色采用偏蓝灰的中性表面，亮色采用冷白与浅灰，强调色统一为蓝色。提交仍使用语义绿色。控件、卡片和浮层的圆角分别使用现有主题 token 的等级，并同步到 Kit。

语法高亮仍沿用 Solarized Dark／Nord Light，终端 ANSI 色表保留。暗色语法中的注释与部分 token 原本低于正文 UI 对比度标准，本次不宣称所有代码文字达到 7:1。

Kit 的 `input` 是边框字段；其暗色输入底色由边框混合透明生成，亮色采用全局背景。不能把该字段当作独立输入底色。继续通过 `Theme::update` 同步颜色、组件 token 和 Base 投影。
