# ZJ

ZJ 是自用、小巧、低资源的 Rust 原生项目查看与 Diff 工具，以多工作区、多 Git 仓库为组织中心。主要用于浏览项目、阅读代码与 Markdown、搜索和跳转，以及集中查看仓库状态与代码差异。

## 产品定位（2026-11-04）

ZJ 舍弃内置 Agent，专注项目查看与 Diff。Agent 工作交给已有的外部工具，ZJ 通过文件与 Git 状态的变化刷新项目内容和差异，不承担 Agent 的启动、对话、编排、审批或会话管理。

- 核心能力：多工作区与多仓库浏览、文件树、搜索、代码导航、Markdown 阅读、Changes、工作区与提交 Diff，以及外部修改后的自动刷新。
- 退出范围：Agent 面板、CLI 桥接、会话历史、模型与额度管理、Agent 专属改动审阅，以及依赖 Agent 的 AI 提交信息生成。已有的通用 Diff、文件监听和 Git 能力继续服务项目查看。
- 功能取舍：既有编辑、Git 写操作和终端能力按需评估，不以完整 IDE 或 Agent 工作台为扩展方向；界面质量与资源占用优先。

内置 Agent 的面板、桥接、会话历史、模型与额度、附件、专属审阅和 AI 提交信息生成已从源码与工作区移除。既有用户会话历史和设置文件不自动删除；旧 `agent` 设置按未知键保留。旧需求、阶段门禁与历史计划见 [开发说明](轻量代码编辑器开发说明.md)，执行记录见 [开发记录](docs/开发记录.md)；与本节冲突的产品范围以本节为准。

当前界面按 VS Code 布局（暗色 Solarized Dark、亮色 Nord Light，跟随系统）：统一标题栏带命令中心，侧栏顶部按「文件／变更／搜索」切换，默认宽 400 px，可拖动调整；右侧是单行标签栏和内容区，底部状态栏。可编辑并保存 UTF-8 文件（原子写入、外部修改提示、可选自动保存），支持全部仓库 Changes、左右对照 Diff、Git 日常操作、Markdown 实时预览、内置终端。未保存编辑在停顿 2 秒后写入恢复快照，异常退出后恢复最近一次已落盘快照；最后一次快照之后的编辑仍可能丢失。

Git 操作结果采用单行摘要，详情按需展开，错误默认展开并保留检查入口；详情支持选中文字复制和完整复制。当前完整界面审阅、统一设计方向及原生验收边界见[功能与交互核查](docs/验收/项目查看与Diff功能缺口.md#当前完整界面与交互审阅2026-11-04)。

## 构建与运行

环境：macOS Apple Silicon、Rust 1.99.0、系统 Git。GPUI Kit 固定为 0.7.1，兼容 GPUI snapshot 固定为 0.3.8，依赖记录在 `Cargo.lock`。运行时 shader 路径已在只有 Xcode Command Line Tools 的 M5 Pro 上编译和启动，不需要本阶段安装完整 Xcode。

在项目目录执行：

```sh
export CARGO_HOME="$PWD/target/cargo-home"
cargo build --release --locked
./target/release/workspace-editor --windows 3
```

每个根目录对应一个窗口；未指定根目录时默认只开一个空白窗口，可在欢迎页或资源管理器里点「打开文件夹」选择工作区，或用「打开文件」单独编辑文件。可用 `--windows 1`、`--windows 3`、`--windows 5` 对照基础占用。原型最多五个窗口。

生成临时功能夹具后启动三个工作区：

```sh
python3 tools/fixtures.py /tmp/zj-fixture-f
./target/release/workspace-editor /tmp/zj-fixture-f/workspace-1 /tmp/zj-fixture-f/workspace-2 /tmp/zj-fixture-f/workspace-3
```

夹具路径必须尚不存在。脚本拒绝覆盖旧目录，不访问真实仓库，不推送，也不联网。

本地 `.app` 原型包由 `tools/package.sh` 用 `dist` profile 生成，位置为 `target/ZJ.app`。这是本机开发用的应用包，未签名公证，也不是 v0.1 发布产物。

应用图标为水墨“个”字竹叶加一枚朱红光标，矢量源在 `crates/app/assets/app-icon/zj.svg`（16 / 32 px 用简化版 `zj-small.svg`），多尺寸 PNG 在同目录的 `ZJ.iconset/`。打包时在 macOS 上用 `iconutil -c icns` 从 iconset 生成 `zj.icns`，没有 iconutil 时复制已提交的 `zj.icns`（由 `tools/make_icns.py` 用同一组 PNG 生成）。改了 SVG 后用 Node.js 与 sharp 运行 `node tools/generate_app_icon.cjs` 重建 iconset、icns 和 Dock 闪烁用的无光标帧，不增加应用运行时依赖。

## 已实现的交互

- 「新建窗口」（`⌘⇧N`）可从 macOS「文件」菜单、标题栏或欢迎页打开空白窗口，共用 Git 服务和文档所有权；关闭最后一个标签后仍可使用快捷键。
- 「打开文件夹」（`⌘⇧O`）和「打开文件」（`⌘O`）使用 macOS 原生选择窗口，欢迎页也有对应入口。取消选择保留当前内容。空白窗口加载所选工作区；已有工作区时，新开窗口并保留原标签，达到五窗口上限时提示先关闭窗口。
- 单独选择文件会在当前窗口打开，也支持工作区外的文件；文件树和搜索范围保持当前工作区。已有文件仍按身份和路径定位到原标签，所有大小与编码限制继续生效。
- 侧栏顶部按「文件／变更／搜索」切换，「变更」角标显示文件变更数；默认宽 400 px，可拖动至 200–520 px，`⌘B` 显示或隐藏侧栏。侧栏与内容区减少重复包边，顶部导航与标签栏对齐。
- `⌘P` 或点击标题栏的命令中心打开「转到文件」：对全工作区路径做模糊匹配，↑↓ 选择，回车打开；查询为空时按最近激活顺序列出最近文件，关闭后仍保留路径，另存为或移动后跟随新路径，不改变标签顺序；不列出 Untitled。历史仅在当前会话内保存，最多 100 个文件。新查询匹配期间显示等待提示，清除上一条查询的候选；等待或无结果时按回车保留输入，方便继续修改。按 Esc 取消命令／选择面板时，焦点回到打开前的输入位置；连续切换选择步骤也保留原返回位置。选择浮层随窗口宽度收缩并保留两侧留白，底部操作提示超长时省略，悬停可查看完整提示。
- 文件树聚焦时，↑↓ 选择可见项目，←→ 折叠／展开或切换父子项，并滚动到选择；`⌘↓` 打开文件并进入编辑器，Enter / F2 保留重命名。读取完成前继续选择树项目或切换标签，会取消旧打开请求，避免迟到结果抢回焦点；行内命名仍使用文本框自己的方向键。
- 原生「编辑」菜单提供撤销、重做、剪切、复制、粘贴和全选，沿当前焦点执行；文件树使用文件剪贴板，Diff 与大文件查看使用已有选择复制，终端支持复制与粘贴。各区域只提供自身支持的动作。
- 资源管理器按 VS Code 规则显示 Git 装饰：文件名按状态着色，文件右侧显示状态字母，文件夹右侧显示圆点。文件类型图标来自 vscode-icons 子集。
- 隐藏文件规则可在设置文件（`⌘,`）的 `hidden_files` 数组查看和编辑，保存后同步刷新所有窗口的文件树、搜索和转到文件。规则按文件或文件夹名称匹配，支持通配符，按列表顺序以最后命中的规则为准；`!` 开头表示显示例外。例如 `[".*", "!.github", "*.log", "!keep.log"]`；隐藏父目录后，其内容一并隐藏。空数组 `[]` 取消这些隐藏规则，`⌘⇧.` 可临时显示隐藏项；`.git` 在文件树中始终省略，索引已有的 `.gitignore` 和资源保护排除仍生效。旧设置文件缺少此字段时，打开设置会补入可撤销的编辑，保存前不改写原文件。
- 目录按展开层级异步枚举，列表只绘制可见行；搜索打开文件后自动展开祖先目录并定位当前文件。手动折叠优先于后台定位。
- 搜索对文件名和相对路径做模糊（子序列）匹配，文件名命中、连续命中和词首命中的结果排在前面；点击结果会打开文件，或定位到已有标签。打开工作区时在后台建立路径索引：Git 仓库（含嵌套仓库和已初始化的 submodule）用 `git ls-files --cached --others --exclude-standard`，遵循 `.gitignore`；非 Git 目录做受限遍历，跳过 `core::EXCLUDED_DIRS`（`.git`、`target`、`node_modules`、`.venv`、`__pycache__`）。两种方式都不跟随目录链接。结果最多显示 300 项，被截断或索引不完整时会提示「部分结果」。文件事件和「刷新目录」都会重建索引。
- 标签栏固定单行并支持横向滚动，切换标签或调整可用宽度后将当前标签滚入可见区；手动滚动不会被普通重绘拉回。右侧「已打开文件」菜单按标签顺序列出文件路径与特殊视图，也包含尚未读取的恢复标签；选择后沿用原有打开与聚焦流程。标签页保留各自的缓冲区与撤销历史；干净标签的关闭按钮常驻显示，未保存的标签显示圆点，悬停时变成关闭按钮，有未保存修改的窗口在 macOS 标题栏上标为已编辑。状态栏显示分支、行列、编码、换行符和语言，点击 LF / CRLF 可转换换行符（下次保存时写入）。相同文件按设备 / inode 与规范路径去重；从另一窗口打开会定位到原窗口。外部原子替换同一路径后再次打开仍保留原缓冲区。
- 保存按 VS Code：`⌘S` 保存，`⇧⌘S` 另存为（系统保存面板），`⌥⌘S` 全部保存，「文件」菜单里有同样的项目；`⌘N` 新建 Untitled-1，第一次保存时询问位置。另存为后按目标目录的 `.editorconfig`、内容与语言规则重新确定缩进，保存期间继续编辑或手动选择缩进时，保留当时设置。写入用同目录临时文件、fsync 后 rename，保留权限；保留原有的换行符和 UTF-8 BOM，文件末尾是否有换行保持原样。符号链接写到它指向的文件，多硬链接文件原地改写；没有写权限的文件提示原因并提供「另存为」。
- 关闭有未保存修改的标签、窗口，或用 `⌘Q` / 「退出 ZJ」退出时，询问「要保存对“X”的更改吗？」（保存 / 不保存 / 取消）；多个文件时列出文件名（全部保存 / 全部不保存 / 取消）。退出会等每个窗口回答，取消则不退出。
- 打开着的文件在磁盘上被其他程序修改：没有未保存修改时静默重新加载；有未保存修改时编辑器上方出现「磁盘上的文件已更改」（重新加载 / 比较 / 保留我的）。保存时发现磁盘已变，询问覆盖 / 重新加载（丢弃我的修改）/ 比较；「比较」打开磁盘版本 ↔ 缓冲区的 Diff。磁盘上被删除的文件保留缓冲区，标签划线并标「已删除」，保存会重新创建。资源管理器里重命名或移动时标签跟随。
- 「文件 → 自动保存」：编辑后 1 秒（默认）、关闭、失去焦点时，菜单勾选当前模式，写在设置文件里；失去焦点包括切换标签、窗口失活，以及从源码或 Markdown 块编辑器转到同窗其他控件。切到关闭或失去焦点时，已在等待的那次延时保存不再执行。
- 每窗口最多打开 20 个文本文件、合计 20 MiB 读入原文。常规文本超过 8 MiB、单行超过 256 KiB 或不是 UTF-8 时使用受限只读查看器，按需读取可见行，支持跳转、查找和复制；查找栏在窄窗口自动换行，状态可悬停查看，关闭后焦点回到只读内容区。带 BOM 的 UTF-16 和显式指定编码的只读视图、受支持图片各走下文的专用入口和预算；其他二进制文件拒绝打开。编辑增长与撤销的字节预算仍待完善；未保存缓冲区已有异常退出恢复快照。
- 全文搜索通过侧栏按钮或快捷键重新调用时，聚焦并全选原查询，新输入直接替换；普通搜索退出替换模式但保留旧替换词。查询旁的展开／收起按钮控制替换模式，展开时空替换词也支持删除预览与逐行替换。查询框按 ↓ 进入结果列表，↑↓ 选择、←→ 折叠／展开或切换父子项，Enter 打开，Esc 回到查询框；隐藏持有焦点的侧栏会将焦点交回可见编辑区。结果按文件分组，文件级替换按钮在替换模式显示，移除结果按钮常驻，匹配行操作在悬停时显示。「从搜索结果中移除」不删除文件、不修改忽略规则；替换按钮的提示区分当前文件与全部结果，全局替换前确认范围。编辑器查找栏随编辑区宽度收缩，宽时查询输入与匹配导航同排、窄时自动分行，计数显示「当前项 / 总数」，悬停查看完整说明或错误；窄编辑区也能使用替换和关闭按钮；替换开关提示展开／收起，只读文件会说明不能替换。
- 全部仓库显示在同一份可滚动列表中，可同时展开多个分组；只渲染可见行。
- Git 图中可直接点击标签，查看标签名、创建者、日期和说明正文并复制；轻量标签会说明没有独立正文。标签详情按需后台读取，超过 256 KiB 时显示错误；签名文本可见，但不验证签名。
- 同一文件同时有 index 与工作树修改时，分别出现在「已暂存」和「Changes（磁盘）」中；点击行加载对应只读 diff，新增行与删除行分别着色。刷新期间仍可打开；未跟踪文件按新增内容显示，冲突文件显示 Git 合并差异，受支持图片显示两侧图片，其他二进制显示 Git 差异说明；空结果与加载错误可见。
- Diff 编辑器按 VS Code 的样子：默认并排，左边 HEAD / 索引，右边索引 / 工作树，标签页写作 `main.rs (索引)` / `main.rs (工作树)`。展示整份文件，两侧行号、整行红绿底、字符级深色高亮、斜纹填充行、语法高亮和同步滚动；标签栏下方的 Diff 上下文栏显示所属仓库、相对路径及比较范围；本地比较也明确磁盘版本与未保存修改、替换前后或冲突双方。上下文栏集中放置上一个 / 下一个更改、并排 / 内联切换、复制完整 Diff 和打开文件；窄窗口下上下文与操作分行。新增或删除的文件直接用内联视图。受支持图片以图片比较显示，其他二进制和 combined conflict 补丁回退为 Git 原文。右侧概览标尺标出所有更改位置，点击跳转。正文只读，支持按字符拖选、跨行选择和 ⇧ 单击扩展选区；行号栏保留整行选择。⌘A 全选当前侧，⌘C 或原生「编辑 → 复制」复制所选原文，保留中文、Emoji 和原始制表符；并排与内联视图均支持。每个更改块悬停时在行号处显示「暂存块 / 还原块」（暂存区 Diff 为「取消暂存块」）；选中若干行后 Diff 上下文栏出现「暂存 / 还原 / 取消暂存所选范围」，用生成的部分补丁 `git apply` 完成，保留 CRLF、制表符和文件末尾无换行；还原前确认。重命名和删除的文件只支持整文件操作。没有三方合并编辑器。
- 源代码管理按 VS Code 的样子：每个仓库一行（名称、分支，悬停时显示提交 ✓、刷新和 ··· 菜单）；「暂存的更改」「更改」带计数，全部取消暂存、全部暂存和放弃全部更改按钮常驻显示，Git 操作期间保留原位并禁用，悬停说明忙碌状态；文件行显示图标、文件名、灰色目录和右侧彩色状态字母（M / A / D / U / R），悬停时可打开文件、放弃更改和暂存 / 取消暂存，点击打开 Diff。放弃前一律确认；未跟踪文件的「放弃」就是删除文件（`git clean -f`，同样先确认）；冲突文件不提供放弃。
- 每个展开的仓库都有提交信息输入框和绿色「提交」按钮，没有改动时也保留，提交操作不可用。仓库标题中的提交按钮不可用时，悬停说明原因（没有更改、存在冲突或正在执行 Git 操作等）。⌘Enter 或按钮提交，缺少提交信息时展开仓库并聚焦输入框；遵循 hooks 和签名设置，成功后清空消息并刷新。对未保存文件暂存时确认使用磁盘版本，缓冲区仍保留。
- 仓库 ··· 菜单里的「推送」确认当前仓库和上游后，只将当前 HEAD 推到已配置上游，不强制覆盖、不连带其他分支或 tags。没有上游时可在发布流程选择远端与分支，确认实际目标后精确推送当前 HEAD，成功后回读上游配置；发布失败不会报成功。结果详情可复制，并隐藏 URL 中的凭据。没有内建凭据管理或自动发布。「抓取」「拉取」「同步更改」沿用系统 Git 的配置和认证。
- 有待拉取提交时，仓库标题显示循环箭头和待拉取／待推送提交数，例如「7↓ 0↑」，悬停提示拉取来源与数量，点击后只拉取；开启「隐藏无变更的仓库」时仍保留待拉取的仓库。打开或重新显示源代码管理、切回活动窗口时会后台检查远端，自动检查间隔至少 60 秒；三个「刷新」入口均可立即检查。自动检查要求源代码管理可见且窗口活动，空闲时不定时联网。检查只更新远端引用，拉取代码需点击按钮；自动检查失败在状态栏和悬停提示中说明，手动检查失败弹窗显示详情。
- 目录、路径索引与 Changes 使用 macOS 原生 FSEvents 自动刷新；共用一个监听器，窗口关闭后释放无用路径。工作区外的 Git common/private 目录也在首次状态查询前接入监听，覆盖 gitfile 和 linked worktree。事件按 200 ms 合并，连续变化最多合并 1 秒；在途扫描完成后补查，空闲时不轮询磁盘。已发现工作树内的事件不会因生成目录名被过滤，Changes 仍由 Git 判断。
- 自动刷新保留目录展开状态、文件标签、dirty 内容和撤销历史；手动折叠优先。打开的 Diff 保留原内容，磁盘变更后自动重新查询；补丁未变时保留滚动位置和光标。干净的编辑缓冲区随外部修改重新加载；有未保存修改时保留内容并提示冲突。
- 激活窗口会补查；「刷新 Changes」和「刷新目录」仍可手动使用。源代码管理静默刷新，保留原列表，不插入扫描进度或取消行；远端检查请求会合并，关闭窗口会取消后台任务，查询仍有超时保护。不显示扫描、陈旧或过期标记；已有列表、空状态和错误在查询期间保持，只有新结果才更新。首次发现完成前不会提示「未发现 Git 仓库」。监听失败会在状态栏显示异常；事件丢失或溢出触发重新扫描。
- 编辑器复用 Kit 的真实 Editor，带行号、Rust、Python、JavaScript / JSX、TypeScript / TSX、JSON、TOML、YAML、Go、Shell、HTML、CSS、C、C++、Java、SQL、Markdown、Diff 高亮（映射见 `crates/app/src/languages.rs`）、选择、复制粘贴、撤销重做及组件内置查找替换。JSONC 使用已有 JSON grammar 的注释与容错高亮，不作为语法校验器；其他语言是纯文本。中文组合输入仍需要实机专项验收。
- 代码跳转（不跑语言服务器，基于 tree-sitter）：⌘ 悬停显示下划线，⌘ 单击或 F12 转到定义（同文件局部变量按作用域解析，跨文件用后台建立的符号索引；多个候选时弹出列表），⌘⇧O 转到文件中的符号，⇧F12 查找引用，⌃- / ⌃⇧- 后退 / 前进。支持 Rust、Python、JS、TS / TSX、Go、C、C++、Java、Bash。打开文件夹的快捷键改为 ⌘K ⌘O（⌘⇧O 让给符号列表，与 VS Code 一致）。
- Markdown 支持分块预览，点击块可直接编辑，`⇧⌘V` 切换源码。相对链接在 ZJ 中打开；本地图片按解码预算加载，远程和 data 图片不加载。
- 终端支持新建、拆分、终止和隐藏面板；⌃PageUp／PageDown 切换已有分组，⌥⌘←／→ 切换拆分窗格，命令面板也提供对应操作。多个分组的标题可横向滚动，长标题保持单行并限宽省略，悬停显示完整标题，右侧操作按钮固定可见。新建或切换终端时，对应分组会滚入可见区域；隐藏面板不终止进程。
- 输入法跟随焦点（macOS，设置 `auto_input_source`，默认开）：进入终端时切到英文输入法；进入后仍可手动切换，编辑器等其他位置不受影响。

后台 Git 采用独立 argv、porcelain v2 NUL 格式、全局最多两个命令和每仓库串行；状态和 diff 结果带 generation，旧任务不能覆盖新刷新。Git 命令清除继承的 `GIT_*` 定位与配置变量，避免命令被导向其他仓库。查询禁用 optional locks 和 fsmonitor。写操作在同一仓库锁内核对身份及状态版本；刷新不取消已开始的写操作，操作期间禁止关闭对应窗口，失败会刷新状态并显示错误。

## 本轮补齐的查看与比较流程（2026-11-04）

- 图片：直接打开 PNG、JPEG、GIF、WebP、BMP、SVG、ICO、TIFF，支持适应窗口、100% 和缩放。GIF／WebP 显示首帧；SVG 提供源码入口，不加载嵌入或外部图片。单张文件最多 16 MiB，独立图片与图片比较在所有窗口中保留及正在解码的像素合计最多 64 MiB；每窗口最多 8 个独立图片标签。Git 图片 Diff 并排显示 HEAD、暂存区、工作区或提交版本，缺失侧有明确提示。
- 比较：文件树和标签菜单可选择文件作为比较基准，与另一文件或剪贴板比较；命令面板和仓库菜单提供引用／merge-base 比较。Diff 支持字面量查找、空白过滤、未变区域默认折叠和最多 8 份固定比较。过滤空白时关闭部分暂存／还原入口，恢复完整差异后可操作，写入始终使用原始补丁。
- 历史与补丁：文件历史跟随重命名，可打开历史完整内容或与当前文件比较；Git 图支持全历史搜索和作者、日期、路径筛选。支持打开补丁、预检、确认应用及导出。外部补丁应用限单个普通文本文件，拒绝二进制、多文件、重命名、链接和 submodule；导出不覆盖已有文件。
- 阅读：保存文本光标和滚动位置，以及具有稳定文件／Git 来源的固定 Diff、各自布局和滚动位置；恢复时重新校验来源，固定比较在选中时读取。剪贴板和临时缓冲区比较不跨重启恢复。工具栏可标记当前干净文件已审阅；检查点按仓库保存在本地，磁盘内容变化后重新待审，不改 Git index。
- 编码：自动识别 UTF-16 BOM，文件菜单支持按 GBK、UTF-16LE、UTF-16BE 只读打开。严格拒绝无效序列和二进制控制字符，不隐式转换后写盘；这些视图不可编辑、保存或另存为。UTF-8 BOM 文件保持原有可编辑行为。解码视图限 8 MiB、单行限 256 KiB。
- 交互：单击文件树复用干净的预览标签，双击或编辑后固定；标签支持窗口内拖动排序，文件顺序在重启后恢复。查找／替换输入框通过 Alt+↑／↓ 浏览各自的有界历史，并保留当前草稿；⌘D 添加下一个未选中的匹配，多选区编辑可单步撤销。搜索详情区分跳过原因与预算限制。
- Git 管理：SCM 菜单提供新目录初始化／克隆、远端查看／添加／修改、本地分支重命名／安全删除／设置上游、merge／rebase／cherry-pick 继续与中止、submodule 更新和 worktree 管理。联网操作仍需用户确认目标；子模块使用展开重写后的实际默认远端并在执行前核对，新克隆使用确认地址。尚未初始化的相对地址、连续重写、默认远端为自身或多地址等无法唯一确认的配置须先用外部 Git 处理。LFS 指针明确提示本地内容缺失，不自动下载。

这些入口已实现并有自动化回归；原生中文输入法、亮暗屏幕视觉和真实远端认证仍须单独验收。逐项证据与限制见[功能补齐进度](docs/功能补齐进度.md)。
